# human-voice: живой текст в голосе бренда

Агент для Claude, который следит за тем, чтобы посты, сценарии и подписи звучали как написанные живым человеком и в голосе конкретного проекта. Он включается сам, когда вы пишете или правите текст, звать его отдельно не надо.

Агент состоит из двух частей.

1. **Скилл `human-voice`.** Общие правила для всех: без длинных тире, без предложений на двоеточиях, без «не просто X, а Y», без «No X. No Y.», без троек, без ИИ-вводных и искусственных списков, с проверкой смысла. Одинаковый для всех аккаунтов и проектов.
2. **Файл «Голос проекта».** Свой для каждого бренда: язык, обращение, степень дерзости, свои и чужие слова, факты, эталонные посты. Именно он настраивает тон. В репозитории его нет, каждый собирает голос у себя под свой проект.

## Установка в claude.ai

1. Скачайте `human-voice.zip` со страницы [Releases](../../releases/latest).
2. Откройте Settings → Capabilities и включите Code execution, если он выключен. Без него агент тоже работает, но проверяет текст вручную, а не скриптом.
3. Там же в разделе Skills нажмите Upload skill и выберите `human-voice.zip`. Убедитесь, что переключатель включён.

Скилл ставится на аккаунт, поэтому каждый загружает его к себе сам.

## Установка в Claude Code

```bash
claude plugin marketplace add anastasiasch-sh/human-voice
```

```bash
claude plugin install human-voice@human-voice
```

Или просто скопируйте папку `skills/human-voice` в `~/.claude/skills/`.

## Голос проекта

Для каждого бренда заведите отдельный Project в claude.ai и напишите в нём: «Собери голос проекта». Агент задаст около десяти вопросов про тон, обращение и запреты и попросит 3–5 постов, которые вам нравятся. Если у бренда уже есть гайд или инструкция, загрузите их, вопросов станет меньше.

Готовый файл положите в Project knowledge этого проекта, а в Project instructions добавьте строку:

> Любой текст для публикации пиши и проверяй скиллом human-voice в голосе из файла «Голос проекта».

В Claude Code файл голоса кладётся в корень папки проекта под именем `voice.md`.

Пустой шаблон лежит в [`skills/human-voice/references/voice-template.md`](skills/human-voice/references/voice-template.md), его можно заполнить и руками.

## Как пользоваться

- Просите написать пост или сценарий: агент напишет и сам прогонит через проверку.
- Вставляете свой черновик: агент проверит его и предложит исправленную версию с короткой пометкой, что поменял.
- Нужны только замечания без правок: напишите «только проверь».
- Агент отмечает `[проверить]` факты, которые не смог подтвердить. Их надо сверить перед публикацией.

## Линтер отдельно

```bash
python3 skills/human-voice/scripts/lint.py --file draft.txt
```

Нужен только Python 3.8+, без зависимостей.

## Что внутри

- `skills/human-voice/SKILL.md`: правила и цикл проверки.
- `skills/human-voice/references/`: русские и английские ИИ-паттерны с примерами, шаблон голоса, вопросы для сбора голоса.
- `skills/human-voice/scripts/lint.py`: линтер.

## Как улучшать

Самое полезное для качества: добавлять в раздел «Эталоны» файла голоса посты, которые зашли. Если агент раз за разом делает одну и ту же ошибку, допишите её в раздел «Не говорим» голоса проекта или откройте issue, чтобы добавить её в общие правила.
